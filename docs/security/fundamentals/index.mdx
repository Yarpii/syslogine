# Security Fundamentals

Strong security starts with strong foundations.

This section introduces the core concepts behind practical infrastructure security, including security principles, risk awareness, and threat modeling. These guides are designed to help you understand **why** hardening decisions matter before you start applying them.

## What you'll learn

- Core security principles
- How to think about threats and attack surface
- How to design with defense in depth in mind
- How to make better hardening decisions across systems and services
